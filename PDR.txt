小组网页 PDR 报告

1. 项目概述

项目名称：what the dog doing – 团队展示网站

目的：展示团队名称、成员信息、期末项目及课程练习，体现专业、简洁、现代的团队形象。

目标用户：课程教师、同学、外部访客。

核心页面：首页、关于团队（含团队成员列表）、每日作业（含5个练习详情页）、期末项目。

2. 设计目标与原则

极简主义：遵循 Apple 设计语言——大量留白、无边框卡片、微妙的阴影、流畅动效。

内容优先：导航清晰，信息层级明确，减少视觉干扰。

一致体验：所有页面保持相同的导航栏、间距、字体和交互反馈。

响应式：完美适配桌面端、平板和手机。

3. 界面设计（颜色系统 & 组件建议）

3.1 颜色系统

用途	色值（HEX）	应用场景
背景主色	#000000	纯黑基底
次级背景	rgba(255,255,255,0.05)	半透明卡片背景
文字主色	#FFFFFF	白色正文
文字次级	rgba(255,255,255,0.7)	灰色辅助说明
强调/链接	#00D4FF	青色高亮（按钮、链接）
强调粉色	#FF00D4	粉色副标题
强调金色	#FFD740	金色小标题
分割线	rgba(255,255,255,0.1)	极细线条

3.2 字体系统

英文字体：-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, Helvetica, Arial, sans-serif（Apple 默认 SF 字体回退）。

中文字体："PingFang SC", "Microsoft YaHei"，保证优雅降级。

字重：标题使用 600（Semibold），正文使用 400（Regular）。

字号：导航栏 14px，大标题 48px（桌面）/ 32px（移动），正文 16px，H4标题 24px（青色），H5标题 20px（粉色），H6标题 18px（金色）。

3.3 组件建议

导航栏：固定在顶部，半透明毛玻璃效果（backdrop-filter: blur(30px)），圆角 16px，滚动时自动隐藏/显示。

卡片：半透明背景，圆角 16px，悬停时轻微上浮（transform: translateY(-5px)）和阴影加深。

按钮：圆角 8px，青色渐变背景，内边距 12px 24px，悬停时上浮效果。

成员头像：圆形（直径 120px），悬停时 360° 翻转动画，配合简洁图标。

图片展示：圆角 8px，带阴影效果，宽度 100%，高度自适应。

代码块：深色背景，等宽字体，最大高度 600px，可滚动查看。

侧边栏目录：左侧固定，自动生成，支持滚动高亮当前章节。

间距：主要内容区距离导航栏 80px，区块之间 64px，卡片内边距 32px。

4. 信息架构与页面设计（多页应用 MPA）

页面文件	页面名称	内容说明
index.html	首页	团队名称 + 大号欢迎语 + 渐变流动背景动画

练习详情页独立：每个练习拥有完整的侧边栏导航和详细内容展示，包含图片、代码、说明文档。

5. 技术方案

纯静态实现：HTML5 + CSS3 + 原生 JavaScript。

架构模式：多页应用（MPA），每个页面为独立 HTML 文件，通过标准链接导航。

路由管理：页面间使用标准 <a> 标签链接，页面内使用 hash 路由切换 section。

数据驱动：成员信息、项目、练习均使用 JavaScript 对象存储，便于修改和扩展。

本地存储：使用 LocalStorage 保存文件上传数据和用户编辑内容。

部署平台：GitHub Pages（将代码保存为 HTML 文件上传至仓库并启用 Pages）。

兼容性：支持 Chrome / Firefox / Safari / Edge 最近两个版本。

6. 核心功能模块

6.1 智能导航栏

自动隐藏：向下滚动超过 100px 时自动隐藏，向上滚动时重新显示。

紧凑模式：查看练习详情时自动缩小尺寸，聚焦内容区域。

毛玻璃效果：半透明背景配合 backdrop-filter 模糊效果，呈现 Apple 风格质感。

6.2 返回顶部按钮

位置：右下角固定定位，距离边缘 2rem。

显示条件：滚动超过 500px 后出现。

交互：点击平滑滚动至页面顶部，悬停时上浮效果。

6.3 成员展示系统

卡片网格：响应式布局，桌面端 3 列，平板端 2 列，移动端 1 列。

悬停效果：卡片上浮、阴影加深、边框高亮。

详情页面：点击卡片跳转至成员个人详情页，展示完整信息。

头像动画：悬停时 360° 翻转动画，背面显示二维码或额外信息。

6.4 练习详情系统

侧边栏目录：自动生成，基于文档标题（H4、H5），支持滚动高亮。

平滑滚动：点击目录项平滑滚动至对应章节。

图片展示：所有截图按顺序展示，带圆角和阴影效果。

代码展示：等宽字体，语法高亮，可滚动查看长代码。

返回列表：每页提供"Back to List"链接，快速返回练习列表。

6.5 文件上传系统

支持格式：PDF、DOC、DOCX、PPT、PPTX、XLS、XLSX、JPG、JPEG、PNG、MP4、MP3。

存储方式：LocalStorage 本地存储（Base64 编码）。

文件大小：单文件限制 50MB。

管理功能：下载、删除、查看文件列表和总大小。

类型识别：根据文件扩展名自动显示对应图标。

7. 非功能性需求

需求类型	具体要求
性能	首屏加载时间 < 1.5s（预加载关键 CSS），图片使用懒加载，GIF 按需加载。
响应式	断点：1024px（桌面）、768px（平板）、480px（手机）、360px（小屏手机）。导航栏在移动端自动调整宽度。
可访问性	语义化 HTML 标签，链接有焦点环，对比度 ≥ 4.5:1，支持键盘导航，图片提供 alt 文本。
SEO	设置 <title> 和 <meta name="description">，使用语义化标题层级，Open Graph 元数据。
健壮性	无后端依赖，错误路由自动重定向到首页，LocalStorage 满时提示用户清理。
数据安全	LocalStorage 数据定期导出备份，敏感信息不存储在客户端，文件上传前进行大小验证。
