Final Project

Health Monitoring System

Our final project is an Arduino-based health monitoring system that can collect and analyze users' physiological data in real-time, and visualize it through a web interface. The system integrates multiple sensors including heart rate sensors, temperature sensors, etc., providing users with comprehensive health data monitoring services.
